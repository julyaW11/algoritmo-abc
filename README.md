# Artificial Bee Colony Algorithm 🐝

O **Artificial Bee Colony (ABC)** é uma Inteligência Artificial (IA) de otimização matemática inspirada no comportamento das abelhas na natureza em busca de fontes de alimento. Ele é amplamente utilizado para encontrar a melhor solução (mínimo ou máximo) em problemas matemáticos complexos.

Neste repositório há 2 versões deste código: uma -com- gráfico e outra -sem- gráfico. 
Esta é a versão sem gráfico, portanto, básica.

## 💻 Versão Básica:
- Roda puramente no **terminal** (console).
- Não possui interface visual, o que o torna **muito mais rápido** e focado exclusivamente na performance dos cálculos.
- Ao final de todas as iterações, ele exibe na tela o melhor vetor encontrado (`Best Solution`) e o valor matemático final da função (`Best Fitness`).


## 🛠️ Tecnologias Utilizadas
- **Python 3.x**
- **NumPy:** Biblioteca utilizada para a manipulação rápida de vetores numéricos e geração de números aleatórios.

## 🚀 Como Executar

1. Instale a dependência:

```bash
pip install numpy
```

2. Execute o arquivo:

```bash
python bee_colony_algorithm(algoritimo_basico).py
```

Ao final da execução, o programa exibirá no terminal a melhor solução encontrada e seu respectivo valor de fitness.
